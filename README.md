\# Cloud-Native Task Management Platform



A production-style DevOps project built from scratch using AWS,

Terraform, Docker, Kubernetes, Linux, and GitHub Actions.



\## Project Goal



Build an automated platform where developers can push application

code to GitHub and have it automatically tested, containerized,

deployed, and monitored in AWS.
